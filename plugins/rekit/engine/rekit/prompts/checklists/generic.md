## Domain checklist: general
- Entry points and triggers (CLI, schedulers, events, APIs, UI actions); configuration and environment dependencies
  (incl. defaults used in production); every external interface with exact formats; persistent data and its
  lifecycle; numeric/time/text handling (rounding, time zones, encodings); error handling and recovery; concurrency;
  security/authorization rules; performance-relevant behavior (batch sizes, caching, timeouts); dead code.
