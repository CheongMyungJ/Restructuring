# S4 펌웨어 개발환경 가이드

작성: FW개발팀 / 최종 수정 2019.05

## 1. 준비물

- Linux PC (Ubuntu 16.04 이상), gcc, make
- (ASIC 디버깅 시) C400 EVB, JTAG (Lauterbach), UART 케이블 115200bps
- ASIC 빌드용 arm-none-eabi 툴체인은 빌드 서버에만 설치되어 있음

## 2. PC 시뮬레이션 빌드

```
$ cd s4fw
$ make            # libssdfw.a, libssdsim.a, tools/ssdcli, tools/imgdump
$ make clean
```

- `libssdfw.a` : 펌웨어 본체 (HAL 미포함)
- `libssdsim.a` : PC 시뮬레이션 HAL (platform/sim) - NAND 모델, timer, 온도센서
- 빌드 옵션은 `config/fw_config.h` 의 `CFG_xxx` 참고. 개발 PC 에서는 기본값 그대로 사용한다.
  특정 옵션을 바꿔보고 싶으면 `make EXTRA_CFLAGS="-DCFG_WL_ENABLE=0"` 처럼 지정.
- sim 의 NAND geometry 는 `config/nand_profile.h` 의 값으로 구성된다.

## 3. ssdcli 사용법

스크립트 파일 또는 stdin 으로 명령을 입력한다.

```
$ cat t1.txt
bad 20 33          # factory bad block 지정 (init 전에)
init               # 전원 인가 (빈 NAND 면 자동 포맷)
write 0 300        # LBA 0 부터 300개 패턴 기록
flush
read 0 300         # 읽고 패턴 비교
smart
c0                 # vendor 카운터 덤프
shutdown           # normal shutdown
save img1.bin      # NAND 이미지 저장
$ ./tools/ssdcli t1.txt
```

주요 명령: `rand <count> <seed>` (랜덤 쓰기), `verify` (전체 검증), `tick <ms> [반복]`,
`temp <C>`, `weak <blk> <page> <level>` (read retry 필요 page 지정), `failprog`, `failerase`,
`cut <n>` (n 번째 program/erase 후 전원 차단), `load <img>`.

전원 차단 시험 예:

```
init
write 0 1000
flush
cut 5
rand 2000 3
init               # 복구 mount - unsafe shutdown 증가 확인
verify
smart
```

## 4. imgdump

```
$ ./tools/imgdump img1.bin [-v]
```

superblock 과 meta ring(checkpoint / journal) page 정보를 출력한다. on-NAND format 확인용.

## 5. 디버그 로그

- sim 에서는 stderr 로 출력. 레벨: 0 off, 1 error(기본), 2 warn, 3 info, 4 trace
- vendor command 0xC1 (cdw10 = level) 로 런타임 변경 가능. `ssdcli` 의 `dbg <level>`.

## 6. ASIC 빌드 / 다운로드

- ASIC 바이너리는 빌드 서버(jenkins `s4-fw-release` job)에서 생성한다. 로컬에서는 빌드되지 않는다.
- EVB 다운로드: factory tool `s4ft download <bin>` (생산기술팀 툴, 별도 배포)

## 7. 코드 작성 규칙 (요약)

- C99, 동적 메모리 할당 금지 (sim platform 제외)
- on-NAND 구조체(`ftl/meta_format.h`) 변경 금지 - 필드 드라이브 호환 필요
- 모듈 prefix: ftl_, gc_, wl_, bbm_, jrnl_, ckpt_, nvme_, smart_, thermal_
- 커밋 전 sim 회귀 스크립트(tests/regress.sh, 개인 PC 별 관리) 실행 권장
